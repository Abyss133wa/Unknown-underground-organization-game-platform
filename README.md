# 游戏邀约平台

面向 150 人左右小群聊的**游戏招募 / 报名规划工具**。有人发起游戏招募并约定时间，群友打开链接即可自由选择参与哪个游戏。仅用于群友规划，不做游戏本体。

- 载体：**网页应用**，手机 / PC 浏览器均可打开（响应式双端适配）。
- 身份：**免注册**，输入昵称即可参与。

---

## 一、当前已实现的功能

### 招募管理（发起人）
- ✅ 发起招募：游戏名称、类型、开始/结束时间、人数上限、开黑渠道、备注、发起人昵称。
- ✅ 发起后自动报名：发布者自动成为自己招募的第一个参与者（1 人局发起后即满员）。
- ✅ 编辑招募（需管理口令）。
- ✅ 删除招募（需管理口令）。
- ✅ 查看「我的招募」（输入昵称，列出自己发布的所有招募）。

### 报名（参与者）
- ✅ 查看招募列表（卡片式，展示时间、人数进度、状态）。
- ✅ 按状态筛选：全部 / 招募中 / 已满员 / 已结束。
- ✅ 报名参与（输入昵称 + 可选备注）。
- ✅ 取消报名（输入昵称）。
- ✅ 查看招募详情与已报名名单。
- ✅ 查看「我的报名」（输入昵称，列出自己报名的所有游戏）。

### 规则与保护
- ✅ 满员自动拦截，且满员后状态置为「已满员」，空出名额后自动恢复「招募中」。
- ✅ 同一昵称不能在同一招募重复报名。
- ✅ 时间冲突软提示：报名时若与已报名的其它招募时间重叠，弹出提示（不强制）。
- ✅ 到达结束时间自动标记「已结束」。
- ✅ 管理口令哈希存储（不存明文），编辑/删除需口令校验。
- ✅ 输入内容前端转义，防脚本注入。

### 管理员
- ✅ 管理员登录（账号 `root` / 密码 `root7788`），登录后顶栏显示「👑 管理员」标志。
- ✅ 管理员可编辑、删除任意招募（免管理口令）；非管理员仍需发起人口令。
- ✅ 退出管理员登录。

## 四、快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务（在项目根目录下）
uvicorn app.main:app --reload

# 3. 浏览器打开
#    首页：        http://127.0.0.1:8000/
#    接口文档：    http://127.0.0.1:8000/docs
```

首次启动会自动创建 `game_invite.db`（SQLite 数据库文件）。

## 五、API 一览

| 方法 | 路径 | 说明 | 需口令 |
|---|---|---|---|
| GET | `/api/games` | 招募列表（?status=open/full/ended） | 否 |
| GET | `/api/games/{id}` | 招募详情 + 报名名单 | 否 |
| POST | `/api/games` | 发起招募（返回一次性管理口令） | 否 |
| PATCH | `/api/games/{id}` | 编辑招募 | ✅ |
| DELETE | `/api/games/{id}?admin_token=` | 删除招募 | ✅ |
| POST | `/api/games/{id}/join` | 报名 | 否 |
| DELETE | `/api/games/{id}/join?nickname=` | 取消报名 | 否 |
| GET | `/api/games/me?nickname=` | 查看某昵称报名的游戏 | 否 |
| GET | `/api/games/mine?nickname=` | 查看某昵称发布的招募 | 否 |
| POST | `/api/admin/login` | 管理员登录（root / root7788） | 否 |

## 六、使用流程

1. **发起**：点右上角「发起招募」→ 填写信息 → 提交 → 复制并保存弹出的**管理口令**。
2. **分享**：把平台链接（或该招募）发到群里。
3. **报名**：群友点开链接 → 点招募卡片 → 「报名」→ 输入昵称 → 确认。
4. **管理**：发起人在详情页输入管理口令，可「编辑」或「删除」自己的招募。

> 管理口令仅在创建时显示一次，请务必妥善保存；丢失后无法找回（只能删除数据库重建）。
